# Story
Курс «Системная инженерия» за два занятия дал компактный, но содержательный набор практических инструментов. Мы разобрали, как формулировать требования по критериям INVEST, и освоили базовую работу с GitHub. Также на лекциях были разобраны такие темы как: вертикальные связи (подсистема, система, надсистема) и горизонтальные (прошлое, настоящее, будущее), анализ по девятиэкранке, а также понятие NVP и его нежелательные функции.
