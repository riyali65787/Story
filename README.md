# Story
Курс «Системная инженерия» за два занятия дал компактный, но содержательный набор практических инструментов. Мы разобрали как формулировать требования по критериям INVEST и освоили базовую работу с GitHub. Также на лекциях были разобраны такие темы как: вертикальные связи (подсистема, система, надсистема) и горизонтальные (прошлое, настоящее, будущее), анализ по девятиэкранке, а также понятиями: 
1. MVP (Minimum Viable Product), что является минимально жизнеспособным продуктом, то есть версией с минимальным набором функций, достаточным для проверки ключевой гипотезы и получения обратной связи от пользователей.
2. NVP (Non-Viable Product) это нежизнеспособный продукт, а точнее упрощённая версия, которая нужна, чтобы быстро и без лишних затрат проверить, что решение не работает, и своевременно отказаться от бесперспективного пути.
