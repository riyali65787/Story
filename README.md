# Story
Курс «Системная инженерия» за два занятия дал компактный, но содержательный набор практических инструментов. Мы разобрали как формулировать требования по критериям INVEST и освоили базовую работу с GitHub. Также на лекциях были разобраны такие темы как: вертикальные связи (подсистема, система, надсистема) и горизонтальные (прошлое, настоящее, будущее), анализ по девятиэкранке, а также понятиями: 
1. MVP (Minimum Viable Product) – это минимально жизнеспособный продукт, то есть работающий прототип с минимальным набором функций, которого уже достаточно, чтобы проверить спрос и получить обратную связь от пользователей, при этом его можно продавать и параллельно дорабатывать и улучшать.
